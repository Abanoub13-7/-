# FOG Dashboard System

نظام متكامل لإدارة:

* الطلبات
* الشكاوى
* العملاء
* الشركات
* الإحصائيات
* الداشبورد الإداري

تم تطوير المشروع باستخدام:

* HTML5
* CSS3
* Vanilla JavaScript

بدون استخدام أي Framework خارجي مثل React أو Vue أو Angular.

---

# نظرة عامة على المشروع

المشروع عبارة عن Dashboard احترافي لإدارة الطلبات والشكاوى والعملاء داخل بيئة عمل إدارية.

يوفر النظام:

* إدارة الطلبات
* إدارة الشكاوى
* إدارة العملاء
* إدارة الشركات والمفوضين
* ربط العملاء بالسجلات
* إحصائيات ديناميكية
* بحث وفلترة متقدمة
* نظام ترقيم ذكي
* LocalStorage persistence
* واجهة عربية احترافية

---

ويشمل:

# نظام الوكيل والموكل

إذا كان مقدم الطلب وكيلاً عن شخص آخر:

* يتم حفظ الوكيل داخل الأفراد
* يتم حفظ بيانات الموكل
* يظهر داخل الجداول:

```text
الموكل
اسم الموكل
```

---

# نظام الشركات والمفوضين

إذا كان مقدم الطلب مفوضًا عن شركة:

* يتم حفظ الشركة داخل قسم الشركات
* يتم حفظ بيانات المفوض
* يظهر داخل الجداول:

```text
مفوض عن شركة
اسم الشركة
```

---

# نظام الترقيم الذكي

يدعم النظام:

* إعادة استخدام الأرقام المحذوفة
* منع القفزات غير المنطقية في الترقيم

مثال:

إذا كانت الطلبات:

```text
1 2 3 4 5 6 7 8 10
```

فالطلب التالي يحصل على:

```text
9
```

بدلاً من:

```text
11
```
